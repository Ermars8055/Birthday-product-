# Birthday Site Assets

Drop your media files in this folder. The site references:

- `birthday-background.mp4` — full-screen hero/reveal background video (autoplay, muted, loop). Use any dreamy birthday/celebration/abstract clip.
- `video-poster.jpg` — static poster image shown before the video loads (optional; a remote Pexels poster is used by default).
- `celebration-sound.mp3` — short celebration sound played after pressing "Make a Wish".
- `memory-1.jpg` … `memory-6.jpg` — optional local memory photos. By default the gallery uses Pexels placeholder images; replace the `memories` array in `script.js` (`birthdayConfig`) with your own paths.

You can change all paths from the `birthdayConfig` object at the top of `script.js`.
